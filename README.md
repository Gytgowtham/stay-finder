# 🏠 Room Listing API

A simple Django REST API project that serves room/property data 
(photo + info) to a frontend HTML page using Fetch API.

## 🚀 Tech Stack
- Python, Django, Django REST Framework
- HTML, CSS, JavaScript (Fetch API)
- SQLite (Database)
- Pillow (Image Handling)

## ✨ Features
- REST API to list rooms with photo and details
- Frontend fetches and displays room cards dynamically
- Admin panel to add/manage room listings
- CORS enabled for frontend communication
